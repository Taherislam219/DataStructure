## Requirements

- A C++ compiler such as **g++**
- A terminal or C++ IDE

Check your compiler:

```bash
g++ --version
```

## Compile and run

Each source file is a separate program. For example, to compile and run the stack implementation:

```bash
g++ -std=c++17 "Stack using Array.cpp" -o stack
./stack
```

For another program, replace the source filename and output name. Keep quotation marks around filenames containing spaces. On Windows, run the generated executable with its `.exe` extension.

Some programs request input in the terminal. Follow the prompts shown by the program; input and output vary by file.

## Suggested learning order

1. Start with linear search and binary search.
2. Practice stack and queue operations.
3. Explore linked lists and tree traversals.
4. Compare a binary tree with a binary search tree.
5. Trace recursive factorial, Fibonacci, and Tower of Hanoi examples.

## Learning goals

- Understand how common data structures store and organize data
- Practice operations such as insertion, deletion, traversal, and searching
- Improve code readability, testing, and documentation as I learn
