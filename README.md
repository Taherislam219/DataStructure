# Data Structure

This repository contains my practice programs for Data Structures and Algorithms using C++. I created these programs while learning the basic concepts and practicing how different data structures and algorithms work.

## Topics Covered

- **Stack:** Stack implementation using an array, including push, pop, peek, and display operations.
- **Queue:** Queue implementation using a linked list, including insertion and deletion.
- **Linked List:** Insertion at the beginning, end, and a specific position, along with deletion operations.
- **Binary Tree:** Creating a binary tree and performing inorder traversal.
- **Binary Search Tree (BST):** Inserting elements, searching for a value, and preorder traversal.
- **Searching Algorithms:** Linear search and binary search.
- **Recursion:** Factorial, Fibonacci series, and Tower of Hanoi.

## Language Used

- C++

## Purpose

The main purpose of this repository is to improve my programming skills and understand how data structures and algorithms work through practical coding.

These programs are part of my learning and practice journey.
